## 🔄 รายละเอียดการอัปเดต v1.000 (Build 140)

- **ปรับแต่งเลย์เอาต์หน้าจอ**: ตรวจจับและปรับการทับซ้อนระหว่างแถบนำทางของเครื่อง (3 ปุ่ม / ท่าทางสัมผัส) กับช่องพิมพ์ข้อความโดยอัตโนมัติ
- **ปรับปรุง UI และการมองเห็น**: ปรับพื้นหลังของกล่องยืนยันการส่งไฟล์และรูปภาพให้เป็นรูปแบบเดียวกัน ช่วยให้อ่านข้อความและปุ่มได้ชัดเจนยิ่งขึ้น
- **ระบบขอลบบัญชีผู้ใช้**: ให้บริการหน้าเว็บสำหรับขอลบบัญชีผู้ใช้ตามนโยบายของ Google Play พร้อมรองรับการเปิดเชื่อมโยงจากในแอป
- **ปรับปรุงความคล่องตัวในการใช้งาน**: เลื่อนหน้าจอลงไปยังข้อความล่าสุดโดยอัตโนมัติเมื่อส่งข้อความและล้างช่องพิมพ์เสร็จสิ้น
- **เพิ่มประสิทธิภาพการแนะนำสติกเกอร์**: แนะนำสติกเกอร์เมื่อพิมพ์คำค้นหาตรงกันทุกตัวอักษร พร้อมล้างข้อความในช่องพิมพ์เมื่อส่งสติกเกอร์
- **สายเรียกเข้าด่วนพิเศษ Zero-DB**: ขจัดขั้นตอนการอ่านเขียนฐานข้อมูลในเครื่องขณะมีสายเข้า ทำให้หน้าจอสายเรียกเข้าเด้งขึ้นทันทีใน 0 มิลลิวินาที
- **ขจัดความล่าช้าในการส่งข้อความ**: ปรับปรุงระบบตรวจสอบสิทธิ์ล่วงหน้าและระบบแจ้งเตือนเพื่อแก้ปัญหาความล่าช้าในการส่งและรับข้อความ
- **เพิ่มความสะดวกในการใช้งาน**: ข้ามการล็อกรหัส PIN อัตโนมัติเมื่อแนบ/เปิดดูไฟล์ในห้องแชท หรือเมื่อแชร์ลิงก์เชิญเพื่อน
- **ยกระดับความปลอดภัยและความเสถียร**: เสริมความแข็งแกร่งของระบบโดยรวมและความต่อเนื่องในการเชื่อมต่อ

## 📱 ขั้นตอนการติดตั้งบน Android

การติดตั้งไฟล์ APK โดยตรงโดยไม่ผ่าน Google Play Store จำเป็นต้องเปิดการอนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ในการตั้งค่าความปลอดภัยของอุปกรณ์

### ขั้นตอน
1. แตะลิงก์ดาวน์โหลดด้านบนเพื่อดาวน์โหลดไฟล์ `booth-messenger-release-v140-com.booth.messenger.apk`
2. เมื่อดาวน์โหลดเสร็จสมบูรณ์ ให้แตะที่ไฟล์ APK จากแถบการแจ้งเตือนหรือจากแอป "ไฟล์ (ดาวน์โหลด)"
3. หากมีข้อความเตือนว่า **"เพื่อความปลอดภัย โทรศัพท์ของคุณไม่ได้รับอนุญาตให้ติดตั้งแอปที่ไม่รู้จักจากแหล่งที่มานี้"**:
   - แตะที่ **การตั้งค่า (Settings)**
   - เปิดสวิตช์ **"อนุญาตจากแหล่งที่มานี้"**
   - แตะปุ่มย้อนกลับ แล้วแตะ **"ติดตั้ง"**
4. เมื่อติดตั้งเสร็จเรียบร้อยแล้ว แตะ **"เปิด"** เพื่อเริ่มใช้งานแอปได้ทันที

## ✨ คุณสมบัติเด่นที่สำคัญ

- **🔒 การเข้ารหัสแบบ End-to-End ระดับกองทัพ (E2EE)**: ข้อความและสัญญาณการโทรทั้งหมดได้รับการเข้ารหัสบนอุปกรณ์ ไม่สามารถดักฟังได้โดยบุคคลภายนอกหรือผู้ดูแลเซิร์ฟเวอร์
- **🛡️ ความปลอดภัยฐานข้อมูลในเครื่องด้วยฮาร์ดแวร์ (SQLCipher)**: ข้อมูลในเครื่องได้รับการปกป้องด้วยคีย์ที่สร้างจากฮาร์ดแวร์ ปลอดภัยแม้โทรศัพท์สูญหาย
- **📞 การโทรสนทนาและวิดีโอคอล P2P ความคมชัดสูง (WebRTC)**: สนทนาทางเสียงและวิดีโอแบบ Peer-to-Peer โดยตรงที่มีดีเลย์ต่ำ พร้อมรองรับบับเบิ้ลลอยขณะสลับไปแอปอื่น
- **⚡ เปิดหน้าจอสายเรียกเข้าทันที (Zero-DB)**: เด้งหน้าจอสายเข้าทันทีแม้ขณะล็อกหน้าจอหรือปิดแอปอยู่ โดยไม่มีความล่าช้า
